# 知径 · 鸿蒙学习应用

本仓库为参赛作品的完整软件交付。知径提供小学数学和 Java 数据结构两门课程，包含知识图谱、练习判题、AI 学习规划、学习路径和桌面待办。

## 评委如何运行

**在 DevEco Studio 中打开仓库根目录，正常同步后选择 entry 并运行 App。App 直接连接作品现有云后端。**

评委电脑无需部署后端、安装 Python 或 Java 判题环境、运行容器、配置数据库，也无需填写 AI API 密钥。Java 判题和 AI API 调用都在现有云后端执行。

1. 克隆仓库或完整解压源码 ZIP。
2. 在支持 HarmonyOS 6.0.2（API 22）的 DevEco Studio 中打开包含本 README、build-profile.json5、AppScope/ 和 entry/ 的根目录。
3. 等待 IDE 完成常规项目同步，选择 entry 和匹配的鸿蒙运行设备，点击 Run。
4. 打开“知径”，选择小学数学或 Java 数据结构，开始体验。

不需要修改 App 的现有后端地址。评审运行设备需要联网，并由作品维护方保持现有云服务运行。

**设备签名：** 仓库不含个人私钥和证书。首次在评委自己的真机安装时，DevEco 仍可能要求正常自动签名；SDK 和设备签名属于 IDE／鸿蒙运行条件，不能通过公开提交者的个人证书来省略。工程的无个人签名构建已验证通过。

详细步骤见 [参赛运行说明](docs/参赛运行说明.md)。

## 目录

| 目录 | 用途 |
| --- | --- |
| AppScope/、entry/、hvigor/ | 可直接由 DevEco 打开的鸿蒙应用工程、资源与构建配置 |
| server/ | 作品后端完整运行代码，包含必要模型、题库和配图，供源码审阅与维护 |
| scripts/ | 工程回归、运行资产检查、安全发布检查和可选后端维护启动器 |
| docs/ | 参赛运行、产品使用与发布验证文档 |

| third_party/ | 第三方许可文本 |

运行工程不依赖研究子仓库，也不需要原始学生记录或模型重训练。当前已实现双课程独立记录、数学选择／填空判分、云端 Java 17 隔离判题、AI 建议接受、路径归档和两种尺寸的鸿蒙桌面卡片。
