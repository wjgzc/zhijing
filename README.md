# 知径

**让学习有方向。**

知径是一款鸿蒙学习应用，支持小学数学与 Java 数据结构。通过知识图谱寻找学习内容，在练习中获得反馈，再由学习助手提供建议，将需要加强的内容安排成可跟进的学习路径。

## 你可以用知径做什么

### 看清知识之间的联系

在知识图谱中逐级浏览模块与知识点，查看所属内容和前置信息。支持单指移动、双指缩放，找到有题目的知识点即可开始练习。

### 练习小学数学

阅读题干、选项与配图，完成选择或填空后查看对错、参考答案与解析。多空题提供逐空反馈，帮助你找到具体出错的位置。

### 练习 Java 数据结构

阅读中文题意、英文原文和输入输出示例，编写或粘贴 Java 17 程序。代码由云端判题，返回编译、运行及测试结果；支持保存代码草稿和修改后重新提交。

### 获得学习建议

告诉学习助手你的基础、提升目标和每天可投入的时间，结合练习情况获取建议。回复中的知识点链接可以直接带你回到图谱，方便边了解、边练习。

### 按路径持续学习

接受一条建议后，在“路径”中查看知识点任务、题号和完成进度。完成整条路径后可以回看历史，也可以根据新的练习情况重新规划。

### 从桌面继续练习

在支持的鸿蒙设备上添加“知径学习待办”卡片，查看当前课程的任务与进度，点击未完成任务继续练习。提供 2×2 和 2×4 两种尺寸。

## 多设备界面

支持手机、平板及 2in1，随窗口宽度调整导航和分栏布局。学习助手使用系统头像，并在 AI 回复末尾显示红色生成提示。[适配说明](docs/ADAPTIVE_UI.md)。

## 开始使用

1. 打开知径，选择“小学数学”或“Java 数据结构”。
2. 进入“图谱”，找到想练习的知识点并开始做题；也可以先到“助手”填写学习基础、目标与时间。
3. 阅读作答反馈，让学习助手结合练习情况生成建议。
4. 点击建议下的“✓ 接受”，在“路径”中查看并完成任务。
5. 在首页或“我的”查看当前计划和学习概览。

两门课程的学习记录分别保存在设备上。使用当前云服务时，不需要注册账号、配置 AI 密钥或在设备上部署判题环境。

## 使用前了解

- **在线功能需要联网。** 题目加载、判题、学习诊断和 AI 回复通过云服务提供，服务可用性与网络状态会影响这些操作。
- **预测值用于辅助安排练习。** 页面中的“掌握度／预测答对率”是模型参考值，不等于正式测验成绩。
- **完成任务表示完成规定练习。** 答错也会形成有效作答，任务完成不代表全部答对或已经学会。
- **记录主要保存在本机。** 当前没有账号云同步；清除应用数据或卸载前应了解本地记录可能丢失。
