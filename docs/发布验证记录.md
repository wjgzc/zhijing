## 未在本轮实际验证

- 付费 AI 上游回复：需要使用者自行配置私有密钥，本轮没有为验证而调用付费服务。
- Java 用户代码的实际容器运行：需配置 Linux Podman／Docker 后执行容器检查；当前 Windows 打包环境未完成该项。
- 真机安装签名、最新资料弹层、深色外观、桌面卡片添加及系统实际刷新：构建和脚本检查不能替代这些设备测试。
- 全新设备从网络安装全部 SDK、OHPM 及 Python 依赖：本轮使用已安装的本机工具与依赖完成构建和启动验证。

## 按运行方式配置

1. 手机安装：自己的鸿蒙签名和设备授权，不能使用仓库中不存在的个人证书。
2. 继续使用现有云后端：App 地址保留，Java 判题和 AI API 都继续在现有服务器执行，手机无需配置 Java、容器或 AI 密钥。
3. 仅在自建 AI 服务时：在忽略的 `server/.env` 中配置自己的 DeepSeek API 密钥。
4. 仅在自建 Java 判题服务时：配置 Linux 容器引擎、Java 17 判题镜像，以及 API 与本机判题进程共享的私有令牌；推荐使用启动器生成临时令牌。
5. 仅在更换后端时：按实际服务地址更新应用中的后端地址并构建；手机 localhost 不指向电脑。

持有人应在密钥提供方撤销或轮换旧密钥。历史清理需要另行协调，且不能替代密钥撤销。当前运行密钥不在本次发布文件中。

现有后端没有用户登录鉴权；公网部署需配置 HTTPS、访问控制和 AI 费用／请求保护。仓库包含练习题的参考答案与测试，不能作为必须保密的正式考试题库。以上边界详见 README。
