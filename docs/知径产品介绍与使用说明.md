## 一、产品介绍

### 1.1 知径是什么

知径是一款面向鸿蒙手机和平板的学习辅助应用。目前提供“小学数学”和“Java 数据结构”两门课程，把知识关系浏览、实际练习、作答反馈、学习情况预测和 AI 学习规划放在同一套操作流程中。

用户可以从图谱寻找知识点并练习，也可以先告诉学习助手自己的基础、目标和每天可投入的时间，让助手生成学习建议，再把接受的建议转成可跟进的学习路径。

知径希望帮助用户回答三个具体问题：

- 当前课程有哪些内容，它们之间有什么联系？
- 我可以从哪些知识点开始练习，做题后会得到什么反馈？
- 接下来优先练什么，怎样查看自己的任务进度？

### 1.2 产品的主要组成

| 组成 | 为用户提供的内容 |
| --- | --- |
| 双课程空间 | 在同一个应用里学习小学数学或 Java 数据结构，分别保留学习记录 |
| 知识图谱 | 以模块、层级、节点和关系展示课程内容，支持缩放、移动和逐级查看 |
| 数学练习 | 展示题干、选项、配图，提交选择或填空答案后查看判分和解析 |
| Java 编程练习 | 阅读中文题意与英文原文，编写或粘贴 Java 代码，查看编译及测试结果 |
| 学习情况诊断 | 根据作答序列计算知识点预测值，辅助识别需要优先练习的内容 |
| AI 学习助手 | 收集学习基础、目标和时间，结合练习情况提供建议并进行文字对话 |
| 学习路径 | 管理已接受的计划、知识点任务、题目进度和已完成路径 |
| 个人展示与进度看板 | 修改当前页面的资料和头像，查看任务、题数及预测指标 |
| 鸿蒙桌面卡片 | 在桌面查看最近使用课程的待办，点击任务唤起练习 |

### 1.3 适合怎样使用

小学数学课程适合围绕知识点、题型和思维关系进行练习；Java 数据结构课程适合希望结合知识结构进行编程练习的学习者。用户也可以把知径用于自主复习、课程功能演示或学习任务跟进。

学习预测和 AI 建议用于辅助安排练习。它们不能替代正式测验，也不能保证某个知识点已经学会。完成路径代表完成相应的练习任务，具体判断规则见后文。

### 1.4 名称和图标

- 应用名称为“知径”，桌面入口名称也为“知径”。
- 图标采用蓝色背景、展开的书页和向上延伸的路径，表达从知识出发、逐步前进的含义。
- 课程选择页和主界面顶部使用同一套品牌图形。

## 二、功能总览与界面地图

### 2.1 启动后的界面结构

从桌面普通启动应用后，首先进入课程选择页。选择一门课程后进入主界面，上方显示当前课程，下方显示五个原生页签。

| 页签 | 页面内容 | 主要操作 |
| --- | --- | --- |
| 首页 | 问候、助手入口、当前计划、学习概览 | 打开助手，查看完整路径 |
| 图谱 | 当前课程的知识关系、节点详情和练习窗口 | 点模块、点知识点、缩放、拖动、开始练习 |
| 助手 | 摸底选择、聊天记录、学习建议 | 开始分析、发送消息、接受建议、重新规划 |
| 路径 | 当前学习路径、任务及题目、历史完成路径 | 去做题、点题号、取消或重规划、展开历史 |
| 我的 | 头像、个人信息、助手快捷卡片、任务和进度看板 | 修改信息、更换头像、打开任务或路径 |

点击底部图标或名称切换页面。课程切换使用主界面顶部的“切换课程”。从桌面卡片启动时，应用会根据卡片所指向的课程与任务打开相应位置，不一定先显示课程选择页。

### 2.2 两种学习入口

**直接练习：** 选择课程 → 打开图谱 → 逐级找到知识点 → 开始练习 → 查看反馈。

**按计划练习：** 选择课程 → 打开助手 → 完成摸底 → 生成并接受建议 → 打开路径 → 按任务练习 → 完成路径。

直接练习不要求预先建立学习路径。有计划时，在图谱中完成该计划所绑定题目的有效作答，也会推进对应任务。

## 三、使用前准备

### 3.1 设备和安装

1. 准备支持当前安装包的鸿蒙手机或平板。
2. 获取与设备适配、能够正常安装的知径安装包。
3. 按当前分发方式完成安装；项目开发调试包需要使用相应的鸿蒙开发安装流程。
4. 在桌面找到“知径”图标并打开。

当前工程的系统兼容配置为 HarmonyOS 6.0.2（API 22），设备类型包含手机和平板。本文不把工程中的调试安装包视为已经发布到应用市场的正式版本。

### 3.2 账号与数据库

当前主使用流程不需要注册、登录或输入密码。用户也不需要自行安装、配置数据库。学习状态由应用在本机保存，在线题目、判题、诊断和助手由相应服务提供。

“我的”页面中的用户名属于资料展示，不是登录账号；修改用户名不会建立云端账户。

### 3.3 网络条件

以下操作需要可用网络及正常运行的服务：

- 首次获取某个知识点的练习题，以及加载需要在线取得的题目图片。
- 提交数学答案。
- 提交 Java 代码并取得判题结果。
- 更新学习情况预测。
- 发送助手消息、生成学习建议和重新规划。

课程图谱随应用提供，已经保存的学习状态和聊天记录保存在本机。即使能离线看到这些内容，也不表示可以离线完成判题或生成新建议。

### 3.4 开始前需要理解的三条规则

1. 数学选择题点击选项就会提交，不需要再点击一个“确认选择”按钮。
2. 任务按“规定题目是否已获得有效作答结果”完成，不以全部答对为条件。
3. 数学与 Java 数据结构分开保存；切换课程后，请先核对页面上方的课程名称。

## 四、第一次使用：完成一轮学习

### 4.1 先做几道题，再生成建议

1. 打开知径，在课程选择页点击“小学数学”或“Java 数据结构”。
2. 点击底部“图谱”。
3. 点击一个模块，逐级进入其下的内容。
4. 点击一个可练习知识点，在底部详情中点击“开始练习”。
5. 按题目类型完成作答：数学选择题点选，填空题填写后提交，Java 题编写代码后提交。
6. 阅读结果。点击“下一题”继续；最后一题的按钮为“完成”。
7. 点击底部“助手”，选择自己的基础或年级、想重点提升的方向、每天可投入的时间。
8. 三项选择齐全后点击“开始分析”。
9. 等待助手返回建议，阅读知识点与练习安排。
10. 认可这条建议时，点击该建议下方的“✓ 接受”。
11. 点击底部“路径”，在当前路径中选择任务并点击“去做题 →”。
12. 完成该路径的全部任务后，到“已完成”区域展开查看。

### 4.2 还没做题，也可以先规划

1. 选择课程并打开“助手”。
2. 完成三项摸底选择。
3. 点击“开始分析”。
4. 阅读生成的摸底学习建议。
5. 点击“✓ 接受”，再进入“路径”开始练习。

没有作答数据时，助手会依据摸底信息与课程代表知识点提供初始建议。此时不能把建议中涉及的知识点理解为已经由真实作答确认的薄弱点。

### 4.3 可以先了解、稍后再决定

收到建议后，可以先点击其中的知识点链接查看图谱，再决定是否接受。未点击“✓ 接受”前，这条建议不会成为正在执行的学习路径。

## 五、课程选择与切换

### 5.1 课程选择页

课程选择页显示品牌图标、“知径”“让学习有方向”，以及两张课程按钮：

| 课程按钮 | 页面说明 | 练习形式 |
| --- | --- | --- |
| 小学数学 | 梳理知识关系，巩固解题基础 | 选择题、填空题等按题目配置展示的数学练习 |
| Java 数据结构 | 连接知识脉络，练习编程解题 | Java 17 标准输入输出编程题 |

点击对应课程按钮即可进入该课程首页。小屏或内容超出可视区域时，可在课程选择页上下滚动。

### 5.2 切换课程的步骤

1. 在主界面顶部点击“切换课程”。
2. 返回课程选择页。
3. 点击想进入的课程。
4. 应用进入所选课程首页，并读取该课程已有的学习状态。

如果重新选择同一门课程，同样回到该课程首页。当前课程在切换前会保存学习状态，另一门课程的记录不会覆盖它。

### 5.3 分开保存的内容

两门课程分别维护：作答序列、已做题目、预测值、薄弱知识点、摸底信息、当前路径、任务进度、已完成路径和助手聊天记录。

因此，数学课程中的“已做题目”不会加到 Java 数据结构课程里；数学中接受的路径也不会作为 Java 的当前路径展示。

个人资料展示不属于这套按课程持久保存的学习数据，详见“我的”页面和保存规则。

## 六、首页

### 6.1 问候与学习提示

首页显示“你好，同学”。下方提示会根据当前课程是否有已做题目变化：没有记录时引导用户到图谱练习；有记录时显示累计已做题数，并鼓励继续巩固。

这里的称呼不会自动替换为“我的”页面中填写的用户名。已做题数的去重规则见第十四章。

### 6.2 “问学习助手”按钮

点击“问学习助手”进入当前课程的助手页。按钮本身只负责打开页面，不会立即接受计划，也不会自动发出一条聊天消息。

### 6.3 当前学习计划

已接受学习路径时，首页会显示：

- 已完成任务数与任务总数。
- 按路径顺序排列的知识点名称。
- 知识点对应的完成或待完成标记。
- 右侧“查看全部 →”入口。

知识点卡片横向排列，可以左右滑动查看。首页预览最多展示前 8 个任务，完整内容以“路径”页为准。点击“查看全部 →”进入路径页；首页的任务预览卡片当前没有单独的直接做题点击动作。

没有正在进行的路径时，显示“暂无学习计划”等引导。此时可通过“问学习助手”或底部“助手”生成建议并接受。

“当前学习计划”对应正在执行的路径，不按自然日自动清零，也没有到午夜自动重置任务的规则。

### 6.4 学习概览

| 指标 | 显示内容 | 阅读方法 |
| --- | --- | --- |
| 综合掌握度／预测答对率 | 数学显示“综合掌握度”，Java 数据结构显示“预测答对率”；尚无预测时显示“待诊断” | 这是模型计算的参考指标，不是正式考试分数 |
| 已做题目 | 当前课程已获得有效作答记录的不同题目数量 | 同一道题反复提交，不会让此数字每次增加 |

圆环是辅助图形。已做题目圆环的显示比例按最多 100 的图形范围绘制，文字仍显示真实累计题数；不要把这个圆环理解为应用替用户设定了“每日 100 题”的目标。

## 七、知识图谱

### 7.1 图谱的用途和内容

图谱用于浏览课程结构、查看知识点之间的关系并进入练习。顶部显示“知识图谱”和当前查看范围；中央为可操作的节点区域；下方为选中知识点的详情。

当前随应用提供的数学图谱含 1,175 个节点，Java 数据结构图谱含 96 个节点。节点包含模块、分类和具体知识内容，不能把节点数直接等同于题目数、可判题知识点数或模型可预测知识点数。

数学图谱顶层分类为：拓展思维、课内题型、知识点、课内知识点、能力、学习能力、思想、题型。

Java 数据结构图谱顶层模块为：绪论、线性表、栈与队列、串、树与二叉树、图、查找、排序。

### 7.2 进入子级

1. 打开“图谱”，初始范围为当前课程的“全部模块”。
2. 点击有子级的模块节点。
3. 图谱切换到该节点及其直接子级。
4. 继续点击有子级的节点，可进一步深入。
5. 点击具体叶子知识点，查看下方详情。

当前层级中央的焦点节点用于表示所处位置，重复点击它不会继续展开。想返回上级时，请使用左上方出现的“←”按钮。

### 7.3 返回上一层

点击图谱标题左侧“←”，返回当前焦点的父级。可连续点击，直到回到全部模块。处于全部模块时不显示这个返回按钮。

### 7.4 移动、缩放和取消选中

| 手势 | 操作 | 作用 |
| --- | --- | --- |
| 单指拖动 | 按住图谱区域并移动 | 平移图谱，查看屏幕以外的节点 |
| 双指捏合或张开 | 两指在图谱区域靠近或分开 | 缩小或放大，以手势中心调整视图 |
| 点节点 | 轻点模块或知识点 | 进入子级或查看详情 |
| 点空白处 | 轻点没有节点的画布区域 | 取消当前选中及相关高亮 |

缩放有上下限，当前范围为 0.4～3.0 倍。缩得很小时，节点名称会隐藏；若只看见圆点，可以放大后再阅读名称。拖动具有边界约束，不会无限移走整张图。

### 7.5 节点颜色、高亮和外圈

- 节点的填充颜色用于区分所属模块。
- 选中知识点时，应用突出显示该节点及相关上级链路，其他可见内容可能变淡。
- 有可用预测且该节点的值大于零时，外圈可能显示预测比例。
- 外圈参考颜色：预测值不低于 60% 时为绿色，40%～不足 60% 时为橙色，低于 40% 时为红色。

模块填充色与预测外圈颜色表达不同含义。没有外圈可能是尚无预测、值为零，或该节点没有相应预测支持，不能据此直接认定已经掌握或完全不会。

### 7.6 知识点详情

选中具体知识点后，详情区域按数据情况显示：知识点名称、所属模块、题目数量、“前置”信息及“开始练习”。

数学课程的“前置”区域显示该节点的上级层级链；Java 数据结构显示图谱中指向该知识点的前置知识关系。阅读时应结合课程区别理解。

详情中的题目数量表示该知识点的题库元数据数量，不等于本轮一定要练完的题目数量。当前每轮通常请求最多 3 道题，实际以练习窗口显示的总数为准。

### 7.7 开始练习与其他页面定位

有题目的知识点会显示“开始练习”。点击后，应用在图谱页打开练习窗口并加载题目；没有题目的节点仍可浏览，但不会提供有效的练习入口。

以下操作也会带你来到图谱：点击助手回复中的有效知识点链接、点击路径中的知识点名称、点击“我的”页面任务名称。应用会定位并高亮对应知识点；“去做题”和题号入口则会进一步打开练习。

当前图谱没有文字搜索框、手动添加节点、编辑关系或下载课程按钮。

## 八、练习窗口与小学数学练习

### 8.1 可以从哪里进入练习

| 入口 | 操作 | 打开位置 |
| --- | --- | --- |
| 图谱详情 | 点击“开始练习” | 对应知识点的一轮练习 |
| 当前路径 | 点击“去做题 →” | 对应任务，优先从未完成题目开始 |
| 路径题号 | 点击“题号 ××” | 该轮题组中的指定题目 |
| 我的任务卡片 | 点击未完成任务旁的“去做题” | 对应知识点练习 |
| 桌面待办 | 点击仍有效的未完成任务 | 对应课程和知识点的练习 |

这些入口最终使用同一套练习与记录流程，不需要分别提交多次来同步进度。

### 8.2 练习窗口的组成

窗口上方显示知识点名称和“✕”关闭按钮。题目区域显示题号、“第几题／共几题”、题干及可用配图；窗口内容较长时可以上下滚动。

题目下方按类型出现选项、填空框或代码编辑区。获得有效判题结果后，显示反馈及“下一题”；到了本轮最后一题，按钮改为“完成”。

### 8.3 每轮题目数量与顺序

- 当前应用按知识点请求最多 3 道题；题目不足时，以实际返回的数量为准。
- 同一次应用运行中，同一课程、同一知识点使用已取得的固定题组。
- 当前题目选择按知识点采用固定抽样方式，重新打开不保证换一批新题。
- 通过题号进入时，从指定题目开始，本轮其余题目排在后面。
- 通过任务进入且存在尚未完成的绑定题目时，优先从未完成题开始。

不能把详情里“有几十道题”理解为应用已经提供了自由翻遍整库、分页选题或随机换题按钮。

### 8.4 数学选择题

1. 阅读题干和配图。
2. 阅读各个选项，包括可能随选项提供的图片。
3. 直接点击自己选择的选项。
4. 等待“正在核对答案…”及服务返回结果。
5. 阅读正确／错误反馈、参考答案与解析。
6. 点击“下一题”，或在最后一题点击“完成”。

**点击选项即提交。** 当前没有先勾选、再点击统一确认按钮的步骤。核对过程中选项暂不可操作；成功判分后，本次打开中的该道选择题会锁定。

结果展示时，参考正确选项使用正确状态底色；如果选择错误，被选中的错误选项使用错误状态底色；其他无关选项可能变淡。应同时阅读文字反馈，不只根据颜色判断。

如需重新作答，可退出后重新进入该题。再次有效提交会继续形成作答记录，但已做题目数按不同题号去重。

### 8.5 数学填空题

1. 阅读题干，确认需要填几个空。
2. 按题目顺序依次填写“第 1 空”“第 2 空”等输入框。
3. 全部输入框均有非空内容后，点击“提交答案”。
4. 核对时等待结果，不重复点击。
5. 查看整题对错，以及每一空的正确／错误和参考答案。
6. 阅读解析与解析配图，点击“下一题”继续。

只输入空格不算填写。单个输入框上限为 500 字符。多个空要分别填写，不要把全部答案合并到第一个框里。

整题以全部空均正确为“回答正确”；部分空正确时，会显示逐空反馈，但这道题的整体作答仍记为错误。

### 8.6 答案怎样填写

数学判分根据参考答案及已支持的等价规则核对，当前不是让 AI 自由判断任意解题过程。

| 类型 | 填写方式示例 | 说明 |
| --- | --- | --- |
| 整数或小数 | `24`、`0.5` | 按题意填写实际结果 |
| 分数 | `1/2` | 支持数值等价比较；例如 `1/2`、`0.5`、`50%` 在相应数值答案下可等价 |
| 常见计算表达式 | `3+5`、`6/2` | 支持范围内的精确数值表达式可以核对，优先输入简洁结果 |
| 判断内容 | `正确`、`错误` | 在对应判断题配置下，也支持部分常见对错写法 |
| 含单位的量 | 按题目要求填写数值或数值加单位 | 已实现部分常见长度、质量、时间、容量、金额、面积和角度单位的比较 |

等价比较有支持范围，不支持任意自然语言论证、任意公式变形或模糊近似。比如 `0.333` 不应被当作精确的 `1/3`。题目已印好单位时，要结合题意填写，避免无意改变单位或填写对象。

### 8.7 题目、选项与解析图片

题干、选项和解析可以包含图片。题干图片加载失败时，会显示配图暂不可用的提示；这并不保证没有图片也能解答该题。

若图片承载必要信息，应恢复网络后重新进入练习再查看。不要把“看不见图片”当成题目要求用户凭空猜测。

### 8.8 数学判题结果与未记录情形

正常判分后，会显示“回答正确”或“回答错误”，并记录本次结果。参考答案和解析在判题后返回，提交前不会完整展示。

网络、服务或参数问题导致无法判题时，会显示错误和“本次未记录作答”。恢复条件后可重新提交；这类失败不会按一道答错题推进任务。

如果出现“这道题的原始答案仍需核实，本次不记录对错”，表示该题当前不能形成有效判分。当前没有跳题按钮，可先关闭窗口并选择其他可练习内容。

### 8.9 下一题、完成和提前关闭

- **下一题：** 当前题取得有效判题结果后，进入下一道。
- **完成：** 本轮最后一题判分后关闭练习窗口。
- **✕：** 可以提前关闭窗口；已成功记录的作答不会因此撤销。

题目判错也可以进入下一题。点击最后一题的“完成”不是额外的提交或保存步骤；作答在有效判题返回并被当前页面处理时已经记录。

如果在判题尚未返回时关闭窗口，应用不会把随后到达的旧页面结果继续写入当前练习。因此，希望保留该次提交结果时，应先等反馈显示再退出。

数学尚未提交的选项、填空输入和本轮窗口位置没有完整的持久草稿恢复功能。关闭后不要假设所有未提交内容都会保留。

## 九、Java 数据结构练习

### 9.1 进入编程题

1. 选择“Java 数据结构”。
2. 在图谱找到有题目的知识点，或从路径、任务卡片进入。
3. 打开练习，阅读题干、输入输出要求和示例。
4. 在代码区编写或粘贴完整 Java 程序。

此课程使用 Java 编程题。小学数学的点选或填空流程不适用于代码提交。

### 9.2 中文题意、英文原文和示例

- 练习页展示当前题目的中文可读题意，以及可用题图。
- 点击“查看英文原文”展开原文，再点击“收起英文原文”关闭。
- 题目提供示例时，依次展示“示例 1”“示例 2”等，每个示例包含输入和输出。
- 页面注明题目来源 UFCG、CC BY 4.0 及 DOI，便于识别来源。

遇到翻译歧义时，可以对照英文原文与输入输出格式理解题目。示例只是阅读材料，应用当前没有自定义输入的单独试运行面板。

### 9.3 运行规则

当前编程题要求：Java 17、从标准输入读取数据、向标准输出打印结果。程序应按照当前题目的格式处理输入，并输出题目要求的内容。

例如，以下程序只用于说明标准输入输出的写法，实际练习应按题目要求编写，不能把它当作任意题目的参考解答：

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int a = input.nextInt();
        int b = input.nextInt();
        System.out.println(a + b);
    }
}
```

程序不要额外打印“请输入数字”等交互提示，也不要依赖手机本地文件、联网访问或图形界面来取得题目输入。判题环境提供题目测试输入并检查输出。

### 9.4 入口类选择

代码区上方有“入口类”及 `Solution`、`Main` 两个按钮。

| 选择 | 程序入口类的对应写法 |
| --- | --- |
| Solution | `public class Solution`，包含 `public static void main(String[] args)` |
| Main | `public class Main`，包含 `public static void main(String[] args)` |

默认入口类为 `Solution`。如果粘贴的是以 `Main` 为入口的代码，应点击 `Main`。入口类选择与实际代码不一致可能导致编译或运行错误。

应用会按题号保存所选入口类。判题过程中暂不可更改入口类。

### 9.5 编辑与草稿

代码区支持输入和粘贴，使用等宽字体。题目提供起始代码时，首次打开可显示起始代码；已有非空本地草稿时优先恢复草稿。

应用会在编辑时保存该题的代码草稿，并在再次打开该题时读取。草稿与题号关联；编辑器内容不代表已经提交成功，也不会自动推进任务。

代码编辑框上限为 60,000 字符，服务还会检查代码的 UTF-8 大小上限。因此包含较多中文等多字节字符的代码，也可能在未达到字符上限时因过长被拒绝。出现此类提示时应精简代码。

当前编辑区是代码文本输入区，没有实现完整 IDE 的语法补全、断点调试或逐行调试功能。

### 9.6 提交代码

1. 检查题目要求和入口类。
2. 确认代码区不是空白内容。
3. 点击“提交代码”。
4. 等待按钮显示“判题中…”及“正在编译并运行测试…”提示。
5. 查看返回结果。

代码为空或只含空白时不能提交。判题中代码编辑与入口类选择暂不可操作，提交按钮也会暂时禁用，以免同一窗口重复发起提交。

### 9.7 判题结果说明

| 页面结果 | 含义 | 接下来可以做什么 |
| --- | --- | --- |
| 全部测试通过 | 当前提交通过该题配置的所有测试 | 继续下一题或完成本轮 |
| 输出不匹配 | 程序能运行，但某个测试输出与预期不同 | 对照实际输出、预期输出和题意检查逻辑及格式 |
| 编译错误 | 程序没有成功编译 | 查看报错，检查语法、类名、入口与导入 |
| 运行错误 | 程序运行期间异常退出 | 检查数组边界、空值、输入读取、除零等问题 |
| 运行超时 | 编译、启动或运行阶段触及判题时间限制 | 检查死循环、算法复杂度或错误的输入等待 |
| 输出过多 | 程序或编译输出超出限制 | 检查无限输出、调试打印或异常信息数量 |

反馈区会显示“通过 ×／× 个测试”和详细信息；结果提供实际、预期输出时，页面也会展示。详细报错和输出可能截断，不是无限长的完整日志。

判题通常在遇到第一个失败测试时停止，所以“通过数”表示在该次判题流程中已经通过的数量，不表示失败后的所有测试都已经逐一运行。

### 9.8 哪些结果会被记录

有效判题结果中，只有“全部测试通过”记为正确；输出不匹配、编译错误、运行错误、超时及输出过多等有效结果记为错误。这些结果可以计入学习分析，并推进对应题目的作答进度。

“网络请求失败”“判题服务暂不可用”“提交过于频繁”等未形成有效判题的服务错误不记录对错。页面会提示“本次未记录作答，可重新提交”等信息。

### 9.9 修改后再次提交

1. 阅读第一次判题反馈。
2. 在代码区修改程序，必要时更改入口类。
3. 点击“修改后重新提交”。
4. 等待并查看新的结果。

重新提交会产生新的有效作答记录，前一次结果不会简单被抹掉。已做题目数仍按同一题号计为一道；当前任务中的这一道题不会因重试而重复增加完成题数。

如果已经有有效判题结果，即使结果错误，也可以点击“下一题”。是否继续修改由用户决定，应用不会强制必须通过全部测试才能继续本轮。

## 十、学习助手

### 10.1 助手能做什么

学习助手可以收集学习基础、提升目标和每天时间，结合当前课程的作答情况生成学习建议；也可以通过文字聊天进一步讨论学习内容。

助手页包含页面标题与状态、摸底区域或摘要、聊天区、输入框和发送按钮。消息按对话顺序显示，可以上下滚动查看。

### 10.2 首次摸底选择

三组选择每组各选一项；选中后可以点同组其他选项替换。

| 项目 | 小学数学 | Java 数据结构 |
| --- | --- | --- |
| 年级／学习基础 | 三年级、四年级、五年级 | 刚接触 Java、掌握 Java 基础、学过数据结构 |
| 想重点提升 | 计数问题、几何图形、应用题、其他 | 线性结构、树与图、查找排序、综合练习 |
| 每天可投入 | 15分钟、30分钟、1小时 | 15分钟、30分钟、1小时 |

三项均完成后，“开始分析”才可操作。点击后应用保存摸底信息，并发送生成学习建议的请求。

这里的“每天可投入”是助手规划时的参考信息，当前不会自动开启计时、闹钟或每日推送。

### 10.3 已有练习与没有练习的区别

有有效作答时，系统依据最近的作答序列计算预测值，并从可预测、可练习的知识点中选出较低项，作为建议依据。

尚无有效作答时，系统选择课程中若干代表知识点，生成覆盖不同内容的摸底建议。用户完成这些练习后，再次生成建议，依据才会包含真实作答结果。

助手的文字会结合摸底选项，但选择某个目标不等于应用已经把题库或图谱永久筛选成该目标的专属内容。

### 10.4 等待回复

点击分析或发送消息后，页面显示“思考中”及加载指示。普通输入框和发送按钮在等待中暂不可操作；应等待本次结束后再继续对话。

当前回复是请求完成后显示，不提供逐字流式生成。服务可能需要较长时间，等待本身不表示手机卡死。

### 10.5 发送普通文字消息

1. 在页面底部输入框点击并输入内容。
2. 点击右侧“➤”发送。
3. 用户消息进入聊天记录，输入框清空。
4. 等待助手回复。
5. 如有需要，继续输入下一条消息。

只含空白的内容不会发送。可询问知识点之间的关系、练习顺序或如何理解学习建议。例如：“我每天只有 15 分钟，应该先练哪一个知识点？”

普通聊天回复与通过“开始分析”“生成建议”“重新规划”产生的可接受建议卡片不同。即使普通聊天中写出了计划文字，也不能假设它一定附带“接受”按钮。需要建立任务时，请使用专门的建议生成入口。

### 10.6 点击知识点链接

助手回复中，受应用识别的知识点链接以可点击的有色下划线文字显示。点击后切换到图谱，定位并选中该知识点；之后可查看详情并开始练习。

普通文字或未经识别的链接不会自动变成知识点操作入口。点击链接只负责查看知识点，不会自动接受该条建议。

### 10.7 接受或不接受建议

待处理建议卡片下方有“✓ 接受”和“✕ 不接受”。

**接受步骤：** 阅读该条建议 → 点击该条消息下的“✓ 接受” → 看到已生成学习计划的提示 → 打开“路径”。

接受后应用创建当前路径，并把该建议标记为“已接受，路径正在进行”。路径使用该条建议生成时附带的知识点列表；如果聊天里存在多条建议，要确认点击的是自己想执行的那一条。

**不接受步骤：** 点击该条建议的“✕ 不接受” → 消息显示已忽略 → 之后可继续聊天或重新生成建议。

不接受不会清除已有作答记录，也不会创建路径。当前没有把“已忽略”卡片一键恢复成待接受状态的按钮。

每门课程同时只能有一条正在进行的路径。已有路径时再接受另一条，会提示先完成或取消当前路径；不会直接覆盖正在执行的路径。

### 10.8 生成新建议与重新规划

完成摸底后，助手页右上方根据状态显示：

- 没有当前路径时：“生成建议”。点击后根据最新情况请求一条新的可接受建议。
- 已有当前路径时：“重新规划”。点击后先出现取消当前路径的确认对话框。

选择“继续当前路径”则保留原路径。选择“取消并重新生成”，会取消当前路径及其任务进度，保留作答与完成历史，再请求新的建议。**新建议仍需再次点击“✓ 接受”，才会成为新路径。**

重新生成失败不会自动恢复已经取消的旧路径；原有作答记录仍保留，可待网络或服务恢复后再次生成建议。

### 10.9 重新摸底

完成摸底后，页面上方显示“摸底：基础／年级 · 目标 · 时间”的摘要。点击旁边“重新摸底”，三组选择重新出现。

重新摸底会清空页面当前的三项选中状态，供用户重新选择；不会直接删除学习历史、聊天记录或当前路径。重新填写后点击“开始分析”生成新的建议，若当前仍有路径，接受其他建议时仍受“一门课程一条当前路径”的限制。

### 10.10 建议状态与聊天保存

| 消息状态 | 含义 |
| --- | --- |
| 显示接受／不接受按钮 | 这条建议尚未处理 |
| 已接受，路径正在进行 | 该建议对应当前路径 |
| 该路径已完成 | 该建议对应的路径已归档 |
| 该路径已取消 | 该建议曾被接受，对应路径后来被取消 |
| 已忽略该建议 | 用户选择了不接受 |

聊天按课程在本地保存。重新打开该课程的助手时会读取记录；当前没有聊天搜索、导出、单条删除、语音输入或附件上传入口。

## 十一、学习路径

### 11.1 路径是什么

学习路径是用户已明确接受的一组知识点任务。每条路径有自己的编号，显示为“学习路径 1”“学习路径 2”等；两个课程分别维护自己的编号和历史。

“路径”页上方显示“我的学习路径”和已完成知识点数，下方分为“正在进行”和“已完成”两部分。

### 11.2 没有当前路径时

页面显示暂无正在进行路径的引导，并提供“让学习助手 生成新路径”按钮。点击引导文字可打开助手；点击生成新路径按钮会请求进入相应规划流程。

尚未完成摸底时，应用会提示先填写摸底信息。完成并生成建议后，需要在助手中点击“✓ 接受”，路径页才会出现正在进行的任务。

### 11.3 当前任务卡片

每个任务通常包含以下信息：

| 信息 | 含义或操作 |
| --- | --- |
| 第 1 步、第 2 步等 | 当前路径中的排列顺序 |
| 知识点名称 | 本任务要练习的内容；点击名称区域可定位图谱 |
| 建议优先 | 当前路径中排列最靠前的未完成任务 |
| 待提升 | 尚未完成的后续任务 |
| 已完成任务 | 此任务绑定题目已全部获得有效作答记录 |
| 掌握度／预测答对率或待诊断 | 知识点当前的预测展示 |
| 练习进度 ×／× 题 | 本任务绑定题目中已有效作答的数量 |
| 去做题 → | 打开该知识点练习；未完成任务显示此按钮 |
| 题号标签 | 点击打开该轮题组中的指定题目；已作答标签带勾 |

“建议优先”用于推荐顺序，当前没有严格锁定后续任务。未完成的后续任务也可以点击“去做题 →”或题号进入。

“第几步”表示任务顺序，不是已经替用户排好的第几天、日历日期或截止时间。

### 11.4 任务题目加载

进入路径页后，应用会为尚未绑定题目的当前任务请求练习题，取得题号后显示进度和标签。加载中会显示“正在加载任务题目…”。

加载失败时显示“题目加载失败，点击「去做题」重试”。网络恢复后，可以点击该任务的“去做题 →”重新尝试。

每个任务在当前路径内绑定一次题组。开始新路径时，旧路径之前的作答不会自动把新任务全部勾选完成，需要在新路径中进行相应练习。

### 11.5 怎样完成一个任务

1. 点击该任务的“去做题 →”。
2. 提交一道题并等待有效判题结果。
3. 继续完成该任务绑定的其余题目。
4. 该任务的绑定题目全部有有效作答后，应用自动标记完成。

不需要手动勾选任务，也没有“直接标记已学会”的按钮。答错题同样属于一次有效作答；单纯打开题目、浏览题干、编辑代码、服务请求失败则不算完成该题。

任务完成的触发点是最后一道所需题目取得有效结果，不必额外返回路径页按保存。完成当前任务时可能出现“已完成该任务的全部题目，任务已完成”的提示。

### 11.6 完成整条路径

当前路径的所有任务完成后，应用会自动：

1. 将整条路径移入“已完成”。
2. 保存该路径的知识点、题目及完成记录，以及归档时已有的预测展示信息。
3. 清空“正在进行”的路径，等待用户接受下一条建议。
4. 更新首页、“我的”中的当前任务，以及桌面卡片快照。

可能出现“完成任务！整条路径已移入「已完成」”提示。此时首页和“我的”不再列出这条路径的当前待办，属于正常归档，并非历史记录被删除。

### 11.7 查看已完成路径

1. 打开“路径”，向下滚动到“已完成（× 条路径）”。
2. 点击该标题行的“展开 ↓”。
3. 点击某条历史路径的标题行，再展开该路径详情。
4. 查看知识点、预测百分比或“待诊断”，以及对应题号。
5. 点击知识点可到图谱查看；点击题号可尝试重新打开对应练习。
6. 再次点击展开区域的标题行，可以收起。

历史路径按最近完成在前展示。历史百分比是归档时保存的信息，不是每次新作答后都会改写的实时成绩报告。

历史题号入口依赖当前可取得的题组。题库更新后如果出现“未找到题号”，不代表已完成路径本身丢失；当前没有覆盖整个题库的独立历史题目检索页。

### 11.8 取消当前路径

1. 点击当前路径上方“取消当前路径”。
2. 阅读确认对话框。
3. 想保留原计划时，点击“继续当前路径”。
4. 确定取消时，点击“确认取消”。

取消会移除当前路径、当前任务完成状态及该路径的题目绑定。已做题目统计、有效作答记录、已有预测和已完成路径会保留；聊天中原建议会相应显示该路径已取消。

被取消的路径不会作为一条已完成路径归档。当前没有“撤销取消”或恢复原路径进度的按钮。

### 11.9 从路径页重新规划

1. 点击“重新规划”。
2. 在对话框选择“继续当前路径”或“取消并重新生成”。
3. 选择取消并重生后，应用转到助手，结合最新作答及上一条路径的信息请求新建议。
4. 等新建议返回，检查安排，再点击“✓ 接受”。
5. 打开“路径”执行新计划。

取消旧路径与接受新路径是两个步骤。新建议还没接受时，路径页可以暂时没有当前任务，这是正常状态。

如果对话框期间路径已经完成或发生变化，可能提示“路径已发生变化，请重新操作”。应用不会继续取消另一条后来变化的路径，返回页面核对后再操作即可。

## 十二、我的页面

### 12.1 页面内容

“我的”页面用于个人资料展示与学习入口汇总，包括头像和资料、“修改信息”、学习助手快捷卡片、“当前学习任务”和“学习进度看板”。页面可以上下滚动。

页面中的卡片是应用内的操作区域；第十三章介绍的“知径学习待办”才是添加到手机桌面的服务卡片，两者不是同一个界面。

### 12.2 默认资料

当前页面默认显示“张三”“计算机科学与技术”“大三”，初始头像为“张”。这些是预置展示内容，不表示应用已经识别用户身份，也不表示已经登录某个账号。

这组个人资料与助手摸底使用不同的数据。修改这里的“年级”不会自动修改数学助手中的“三年级／四年级／五年级”选择，反过来也一样。

### 12.3 修改个人信息

1. 在“我的”页面点击“修改信息”。
2. 打开原生半模态面板后，查看“用户名”“身份信息”和“年级”。
3. 如要更改用户名，在用户名输入框输入新内容。
4. 如要更改身份信息，在对应输入框输入新内容。
5. 点击想选的年级。
6. 点击“确认修改”，应用关闭面板并更新当前页面显示。

用户名和身份输入框以“当前：原内容”作为占位提示，初始输入内容为空。如果保持为空或只输入空白，确认时保留原内容；不能用空白操作将字段清空。输入内容两端的空白会被去掉。

年级当前提供：大一、大二、大三、大四、研一、研二、研三。当前并未把这里的选项按小学数学课程改成小学年级。

点击“取消”可放弃本次资料修改。面板使用系统提供的关闭与交互方式，实际布局以设备呈现为准。

### 12.4 更换头像

1. 点击个人资料区域的圆形头像。
2. 在头像面板中查看六个候选项。
3. 点击一个候选项，选中边框随之变化。
4. 点击“确定”关闭面板。

六个头像为内置彩色文字头像，文字分别是“张、李、王、赵、孙、周”。点击候选项时就更新选中值，“确定”主要用于关闭面板；当前没有拍照、相册上传、自定义裁剪或图片头像功能。

### 12.5 个人资料的保存限制

当前用户名、身份、年级和头像选择只存放在页面状态中，没有接入学习数据使用的持久保存逻辑。

同一页面实例仍在时可以保留已修改显示，但切换课程导致页面重建、关闭重启应用等情况后，可能恢复默认资料。不能把它当作已经长期保存、会随账号同步的个人档案。

### 12.6 学习助手快捷卡片

点击写有“知径学习助手”“点击快速对话”的小卡片，打开当前课程的助手页。该卡片只负责页面跳转，不会替用户自动发送消息。

### 12.7 当前学习任务卡片

有当前路径时，卡片显示已完成任务数／总任务数及各个知识点：

- 点任务名称或左侧区域：定位图谱中的对应知识点。
- 点未完成任务右侧“去做题”：直接进入练习。
- 已完成任务：显示完成标记及“已完成任务”，右侧不再提供未完成任务的做题按钮。
- 点标题旁“查看路径 →”：进入完整路径页。

暂无当前路径时，卡片显示引导。点击这段引导可以进入助手，接受新的学习路径。

### 12.8 学习进度看板

看板显示当前课程的综合掌握度／预测答对率、已做题目、待完成任务，并提供“问学习助手”“查看路径”两个按钮。

“待完成任务”是当前路径的未完成知识点任务数，不是还有多少题、多少历史错题或今天还要学多少分钟。没有当前路径时可以显示为 0。

## 十三、桌面学习待办卡片

### 13.1 卡片的用途

“知径学习待办”是鸿蒙桌面服务卡片。它把当前学习计划的简要待办放在桌面，方便用户不先进入应用主界面就能看到进度，并从有效待办直接进入练习。

卡片展示的是最近使用课程的快照。切换课程后，应用会发布新的卡片内容；当前没有把某张卡片永久固定为数学、另一张永久固定为 Java 的独立配置入口。

### 13.2 两种尺寸

| 尺寸 | 展示内容 |
| --- | --- |
| 2×2 小号 | 标题、课程简称、完成摘要、进度、最多 2 项任务与底部入口 |
| 2×4 宽版 | 标题、课程简称、完成摘要、进度、最多 3 项任务，并可显示任务题目进度或状态 |

列表优先排列未完成任务，再显示已完成任务。名称过长时会省略，完整名称可到应用里查看。任务总数超过卡片可见项数时，底部显示“查看全部 × 项”。

### 13.3 添加到桌面

1. 安装包含服务卡片的知径版本。
2. 先打开一次应用并选择课程；已有计划时，卡片可以直接展示该计划的内容。
3. 回到手机桌面，长按“知径”图标。
4. 在设备提供的服务卡片入口中找到“知径学习待办”。
5. 选择 2×2 或 2×4 尺寸，按系统操作将其添加到桌面。

服务卡片的系统菜单名称、添加手势和排版因设备版本而异。应用不会在后台自动替用户把卡片摆放到桌面；添加这一步需要通过设备桌面完成。

没有学习计划也可以添加卡片，此时显示还没有待办的提示和打开应用的引导。

### 13.4 卡片各处点击后的行为

| 点击位置 | 结果 |
| --- | --- |
| 标题行或底部入口 | 打开卡片对应课程；有当前路径则进入路径页，没有则进入助手 |
| 仍属于当前路径的未完成任务 | 打开对应课程并进入该知识点练习 |
| 已完成任务 | 打开路径或助手，不按一个新待办重新启动该任务 |
| 没有计划时的引导内容 | 打开应用中的相应规划入口 |

应用会核对计划编号、知识点和完成状态。旧卡片上的任务如果已取消、已完成或已被新计划替换，不会按过期参数直接启动一轮旧待办练习。

### 13.5 卡片显示什么进度

顶部摘要“已完成 ×／× 项”按知识点任务计数。进度条为已完成任务数除以任务总数后的百分比。

宽版任务右侧在题组信息可用时显示“已作答题数／该任务题数”；已完成任务显示“已完成”；尚未显示题组总数的未完成任务可能显示“去练习”。

整条路径归档后，卡片不再保留一组永久的 100% 当前待办，而可能显示“已完成 × 条学习路径”“本轮没有待办”等内容，提示继续规划。

### 13.6 刷新规则与延迟

应用在计划、任务进度和课程变化时尝试刷新已添加的卡片；应用回到前台时也再次同步。系统还会按配置周期调用刷新，当前配置对应约 30 分钟，但实际时机由系统调度，不能保证精确到分钟。

如果刚做完题桌面仍是旧数据，可以先确认应用内进度已变化，再回到应用前台一次并返回桌面查看。卡片更新失败可能等待下一次系统刷新，不表示需要重复提交同一道题。

卡片读取本地计划快照，不需要为了展示待办持续在后台请求 AI，也不会直接在桌面展示完整聊天、数学答案或 Java 源码。

### 13.7 使用卡片的一轮流程

添加卡片 → 在应用中接受路径 → 桌面查看待办 → 点击未完成任务 → 作答并等待结果 → 返回桌面看进度 → 完成全部任务后到应用规划下一轮。

## 十四、学习数据与指标说明

### 14.1 已做题目数

“已做题目”按当前课程中不同题号去重统计。相同题目有效提交 3 次，累计不同题目数仍只增加 1；如果是 3 个不同题号，才是 3 道题。

错误答案也会计入已做题目。加载题目、查看解析、编辑代码而未有效提交，或服务失败未记录，不会单独增加题数。

### 14.2 作答记录与题数不同

应用会保留有效作答序列，用于分析先后发生的正确或错误结果。因此，同题重做虽然不增加不同题目数，仍可以增加作答记录并影响之后的诊断。

当前界面没有按日期列出每次提交的完整历史列表，不能把“系统保存了作答序列”理解为已经提供独立的提交历史管理页。

### 14.3 “待诊断”与 0%

- “待诊断”：当前还没有可展示的预测结果。
- “0%”：已有预测向量后，相关展示得到零值；与尚无诊断不是同一状态。

做题后服务可能仍在计算或请求失败，页面不会必然立刻从待诊断变成百分比。预测失败时已有作答仍可保留，已有预测展示也可能继续保留。

### 14.4 综合掌握度与预测答对率

数学页面沿用“综合掌握度／掌握度”的标签，Java 数据结构页面使用“预测答对率”。两者的底层数值都是模型根据作答计算的预测答对概率，不是对真实掌握程度的直接测量。

首页及“我的”的总体百分比，来自当前有效范围内知识点预测值的平均后取整；并不是当前用户答对题目数除以已做题目数。

预测并非仅根据一个知识点上一道题的对错变化。完成一道题后其他预测也可能改变；一次答对也不能保证某个数值必然上升到指定比例。

### 14.5 预测支持范围

Java 数据结构图谱包含可展示内容与模型支持评分的范围。没有训练覆盖的节点仍可能可以浏览和练习，但不会作为有可靠模型覆盖的薄弱点来推荐。

部分页面在已经有整体诊断时仍可能给无支持节点显示零值，不能把这种展示理解为模型已真实测出该知识点为 0% 水平。是否可练题、是否在图谱中、是否支持预测是三个不同条件。

### 14.6 两类进度

| 指标 | 计算对象 | 例子 |
| --- | --- | --- |
| 当前路径任务进度 | 已完成知识点任务数／本条路径任务数 | 8 个任务完成 2 个，显示 2／8 |
| 单任务题目进度 | 已有效作答的绑定题数／本任务绑定题数 | 3 道题提交过 2 道，显示 2／3 |

同一道绑定题反复提交不会把 2／3 变成 3／3。需要完成剩余那个题号的有效作答。

### 14.7 三个容易混淆的概念

| 概念 | 当前含义 |
| --- | --- |
| 已作答／任务完成 | 已经做过规定的题目并取得有效判题结果 |
| 回答正确／全部测试通过 | 某一次提交满足该题的判分或测试要求 |
| 已经掌握 | 需要结合实际理解、迁移与后续表现判断；当前应用不提供一项绝对保证 |

例如，任务中 3 道题均得到错误结果，任务仍可能完成，但这不代表 3 道题均答对，也不代表对应知识已经学会。

## 十五、保存、恢复与联网范围

### 15.1 当前保存方式速查

| 内容 | 当前保存方式与恢复行为 |
| --- | --- |
| 数学学习状态 | 本机持久保存，进入该课程时读取 |
| Java 数据结构学习状态 | 与数学分开在本机持久保存 |
| 当前与已完成路径 | 随对应课程学习状态保存 |
| 任务绑定题号和作答进度 | 随当前路径保存 |
| 摸底选择 | 随对应课程学习状态保存 |
| 助手对话和建议处理状态 | 按课程在本机保存并读取 |
| 最近使用课程 | 本机保存，供状态恢复与卡片同步使用；普通启动仍有课程选择页 |
| Java 代码草稿与入口类 | 按题号本机保存，再次进入题目时读取 |
| 个人信息与头像 | 仅当前页面状态，未实现长期持久保存 |
| 数学未提交输入 | 当前练习页面状态，没有完整持久草稿 |
| 当前图谱焦点、缩放与位移 | 页面交互状态，没有承诺跨重启完整恢复 |
| 题目内容缓存 | 当前应用运行中的内存缓存，不是完整离线题库 |
| 桌面待办 | 本地展示快照，供卡片扩展读取 |

### 15.2 重启与课程重建

正常关闭再打开应用后，持久学习记录可在选择对应课程后读取；这不保证所有上次打开的窗口、滚动位置和未提交输入也一并恢复。

切换课程会重建该课程相关界面。已经持久保存的学习状态可以恢复，未持久保存的个人资料展示、某些临时编辑内容则可能重置。

### 15.3 清除数据、卸载和换设备

当前没有账号云同步、应用内导出、导入或手动备份按钮。清除应用数据或卸载后，本地记录和草稿可能丢失；换一台设备也不会因输入同样的用户名就自动取得原记录。

工程包含系统备份恢复声明，但当前没有提供用户可操作的备份流程或完成全面恢复验收。不要仅凭该声明就假设卸载、重装、换机一定可以恢复全部内容。

### 15.4 在线请求涉及哪些内容

为了完成相应操作，应用会向服务发送必要数据：

- 获取题目：当前课程、知识点和请求题数。
- 数学判题：当前课程、题号、知识点及填写的答案。
- Java 判题：当前课程、题号、源代码及入口类。
- 学习诊断：当前课程及最近的作答记录。
- 学习助手：当前课程、摸底信息、最近作答和对话内容；后台会调用 AI 服务生成回复。

当前诊断与助手请求最多使用最近 200 条作答，助手对话请求最多附带最近 60 条消息。这个请求范围不等于本机只保存这些数量的记录。

“不需要数据库”与“完全离线”没有等同关系；本机持久记录与联网取得题目、判题、建议同时存在。

## 十六、外观、原生交互与操作习惯

### 16.1 浅色与深色外观

应用已配置浅色和深色颜色资源，并设置为跟随鸿蒙系统颜色模式。用户在设备系统设置中切换深色模式后，使用对应资源的文字、页面、卡片和控件采用相应配色。

当前应用内没有独立主题切换按钮、换肤页或自定义主题色入口。部分插图、图谱模块颜色和品牌区域保留其自身颜色，不应预期所有像素都变为同一种深色。

最新配色尚未完成全面真机验证。若系统模式改变后个别区域表现不一致，需要作为后续界面验收事项处理，本文不把资源已配置等同于所有设备效果已验证。

### 16.2 当前采用的原生界面能力

底部五个页签使用 ArkUI 原生 Tabs；资料和头像编辑使用原生半模态面板；首页圆环、路径进度和卡片进度采用原生 Progress；加载等待使用 LoadingProgress；取消路径使用系统对话框；桌面待办采用鸿蒙 Form Kit 服务卡片。

这些控件承载的是原有操作流程。练习窗口当前仍是图谱页内的练习浮层，不要把所有浮层都理解成已经改为系统半模态页面。

### 16.3 长内容与滚动

- 首页、“我的”、路径列表、聊天记录和练习题正文可以上下滚动。
- 首页当前任务预览是横向滚动。
- 图谱区域使用拖动与双指缩放。
- 长名称在部分狭窄区域会省略，进入详情查看完整信息。
- 输入内容时使用系统键盘；数学填空与代码输入按实际题型填写。

练习退出请使用练习标题右侧“✕”；图谱返回上层请使用图谱标题左侧“←”。当前没有承诺系统返回手势在所有浮层中都等价执行这两个自定义动作。

## 十七、典型使用场景

### 17.1 小学数学：发现需要加强的内容

1. 在课程选择页选择“小学数学”。
2. 打开“图谱”，从当前想练的模块逐级找到知识点。
3. 进入练习，按题型提交答案，阅读逐空反馈或选项反馈。
4. 完成本轮后返回首页，查看已做题目和诊断展示。
5. 进入助手，选择年级、提升目标和每天时间，点击“开始分析”。
6. 阅读建议，点击知识点链接确认内容是否合适。
7. 接受一条建议，在路径页开展下一轮练习。
8. 结合题目解析继续巩固，而不是只追求路径显示完成。

### 17.2 Java 数据结构：边看结构边练代码

1. 选择“Java 数据结构”，打开图谱中的“线性表”“树与二叉树”等模块。
2. 找到有练习题的知识点并开始练习。
3. 阅读中文题意、输入输出示例；有歧义时展开英文原文。
4. 选好入口类，编写完整 Java 17 程序。
5. 提交并阅读编译或测试反馈。
6. 输出不匹配时检查题意、实际输出与预期输出；编译错误时先修复语法或入口问题。
7. 修改后重新提交，或在有有效结果后继续下一题。
8. 到助手生成建议并接受，用路径安排下一阶段内容。

### 17.3 每次只有十几分钟

1. 打开当前课程的“路径”或桌面待办。
2. 选择“建议优先”的任务，或自己需要练习的未完成任务。
3. 完成一道题并等待反馈。
4. 有时间继续下一题；时间不足时关闭窗口。
5. 下次从任务入口继续，应用会优先寻找该任务尚未完成的绑定题。

当前没有学习倒计时功能，时间需自行安排。Java 代码可以有草稿，数学未提交输入则不应假设一定恢复。

### 17.4 想换一个方向，重新安排计划

1. 如学习目标或每天时间改变，先到助手点“重新摸底”并重新填写。
2. 如果仍有当前路径，点击助手或路径中的“重新规划”。
3. 阅读取消提示；确定放弃当前路径进度时，选择“取消并重新生成”。
4. 等待新建议返回，检查内容。
5. 点击“✓ 接受”，再到路径页开始。

历史有效作答保留，新路径的任务进度重新计算。当前没有只删除一项任务、拖动顺序或在保留全部进度的同时直接编辑现有路径的入口。

### 17.5 在两门课程间交替学习

1. 在数学课程完成一部分练习，并等待提交结果记录。
2. 点击顶部“切换课程”，选择 Java 数据结构。
3. 在 Java 中查看、建立或继续其自己的路径。
4. 再切回数学，读取数学原有学习状态。

两门课程可以各有一条当前路径。桌面卡片跟随最近使用课程更新，不会同时把两门课程的任务混成一条列表。

### 17.6 展示产品的一条连贯路线

课程选择与品牌 → 首页当前计划和概览 → 图谱逐级展开与缩放 → 实际作答和反馈 → 助手摸底与知识点链接 → 接受建议 → 路径任务与题号 → 我的进度看板 → 桌面待办。

做演示时，可先确认设备安装了当前版本、服务可用，以及是否已有当前路径。如果已有路径，接受另一条建议会受到当前路径限制，需要按实际情况展示继续或重新规划。

## 十八、常见提示与处理方法

### 18.1 按提示处理

| 提示或现象 | 通常说明什么 | 可以怎样处理 |
| --- | --- | --- |
| 待诊断 | 暂无可展示的预测结果 | 先做题并等待有效判分；若一直不更新，检查网络和诊断服务 |
| 该知识点暂无题目 | 当前节点没有可取得的练习题 | 返回图谱，选择有练习入口的其他知识点 |
| 加载题目失败 | 网络、服务或题目读取失败 | 恢复网络后重新点“开始练习”或“去做题” |
| 未找到题号 ×× | 当前题组不包含被请求的题号 | 从当前知识点普通练习入口重开；历史题组变化需维护方核对 |
| 课程已切换，请重新打开练习 | 请求发出后课程发生变化 | 确认当前课程，再从该课程的入口打开练习 |
| 正在核对答案… | 数学答案正在等待服务判分 | 等待返回；不要在期望记录本次结果时提前关闭 |
| 请完整填写 × 个答案 | 答案数量不符或存在空答案 | 按空的顺序完整填写后重新提交 |
| 本次未记录作答 | 未取得可记录的有效判题结果 | 保留输入或草稿，检查具体原因后重试 |
| 原始答案仍需核实 | 当前题目暂不具备可靠的判分参考 | 关闭该轮，练习其他内容；等待题目维护 |
| 原题配图暂不可用 | 图片加载失败 | 若图片必要，恢复网络并重新进入，避免凭缺失信息作答 |
| 正在编译并运行测试… | Java 代码已进入判题流程 | 等待结果，不重复提交 |
| 编译错误 | Java 程序没有编译成功 | 阅读详细报错，检查入口类、语法和依赖 |
| 提交过于频繁／服务返回 429 | 服务在限制短时间提交频率 | 稍后再试，不连续点击重复提交 |
| 判题队列忙 | 当前判题资源繁忙 | 稍后重新提交，页面草稿不等于已判题 |
| 判题服务暂不可用／服务返回 503 | 服务当前无法提供相应能力 | 等服务恢复；如果持续出现，由维护方检查服务 |
| 课程数据或模型尚未部署 | 当前服务未能提供所选课程 | 保留本地记录，联系维护方核对课程服务 |
| 掌握度诊断失败 | 已作答但预测更新未成功 | 不必为此重复答题；网络恢复后可重新进入练习再触发更新 |
| 请先完成摸底信息 | 规划流程还缺基础、目标、时间选择 | 到助手完成三项选择并开始分析 |
| 该建议没有可用知识点 | 该卡片没有可创建任务的知识点列表 | 使用“生成建议”重新请求一条建议 |
| 请先完成或取消当前路径 | 当前课程已有正在进行的路径 | 继续原路径，或按取消／重新规划流程处理 |
| 路径已发生变化 | 确认对话框期间原路径状态改变 | 返回路径页核对，再决定是否重新操作 |
| 助手返回请求失败或后端配置提示 | 网络、AI 服务配置或上游响应异常 | 先等待请求结束，再检查网络；配置问题需维护方处理 |
| 桌面卡片仍显示旧内容 | 卡片刷新尚未完成或系统调度延迟 | 打开应用核对真实进度，再返回桌面；不要据此重复作答 |
| 修改资料后重启恢复默认 | 个人展示资料尚未持久保存 | 按当前版本限制理解，不能当作学习记录一起长期保存 |

### 18.2 遇到网络失败时的顺序

1. 先看失败发生在加载题目、判题、诊断还是助手阶段。
2. 阅读完整提示，区分“回答错误”和“本次未记录作答”。
3. 检查设备网络是否恢复。
4. 确认当前课程和题目没有在等待期间切换。
5. 对加载或判题按原入口重试；助手失败后，重新输入消息或点击生成建议。
6. 多次稳定复现的服务错误，记录课程、题号、操作步骤和页面提示，交给维护方排查。

当前没有统一的“一键修复”页，也没有为失败聊天自动重新发送的专用按钮。将维护信息保留在自己的记录中即可，应用内尚未提供问题反馈上传入口。

### 18.3 进度看起来不一致时

先核对正在看的是否是同一课程，再核对对象是“当前路径任务数”“单任务题数”“累计不同题数”还是“模型预测百分比”。这些数值表达不同对象，不要求互相相等。

例如：同一 Java 题提交 3 次，累计题数可能仍是 1；当前任务题目进度为 1／3；只有一个任务全部绑定题完成后，路径任务进度才会增加。预测百分比则可能独立变化。

## 十九、常见问题

### 19.1 必须先接受路径，才能做题吗？

不需要。可直接到图谱选知识点练习。接受路径是为了形成可跟进的任务列表。

### 19.2 必须先做题，才能让助手分析吗？

不需要。无作答时可以根据摸底信息生成初始摸底建议；有作答后再生成，建议才会结合实际练习情况。

### 19.3 为什么看到建议后路径页还是空的？

需要点击对应建议下的“✓ 接受”。仅阅读回复、点知识点链接或发送一条聊天消息，都不会自动建立当前路径。

### 19.4 为什么这条回复没有“接受”按钮？

普通聊天回复不会统一附带任务接受操作。请使用“开始分析”“生成建议”或相应重新规划入口请求可接受建议。

### 19.5 有多条建议时，可以全都接受吗？

当前每门课程只允许一条正在进行的路径。可以选择一条接受，其他建议保留在聊天中；想切换执行其他建议，先完成或取消现有路径。

### 19.6 重新摸底会清空学习记录吗？

不会直接清空已有作答、聊天或已完成路径，也不会自动取消当前路径。它让用户重新填写摸底选择。

### 19.7 重新规划会自动创建新计划吗？

不会。确认取消旧路径后先请求新建议，用户还要接受新建议。请求失败时也不会自动恢复已取消的旧路径。

### 19.8 做错题，任务为什么也完成了？

任务检查的是规定题目是否已经有效作答。它没有要求全部答对。请结合实际反馈和解析判断是否还需要练习。

### 19.9 Java 编译错误也算一次作答吗？

有效返回的编译错误属于判题结果，会记录为错误。服务不可用、限流或网络失败等未形成有效判题的情况不记录对错。

### 19.10 点“下一题”才会保存吗？

有效判题结果返回并被页面处理时就会记录。“下一题”负责切换题目，最后的“完成”负责关闭本轮窗口。

### 19.11 我提交后立刻关闭窗口，会怎样？

如果结果还没有被当前页面接收处理，之后返回的旧请求结果会被忽略。需要保留本次结果时，等看到反馈再关闭。

### 19.12 为什么同一题做了很多次，已做题数不变？

因为已做题数按不同题号统计。同题多次有效提交仍保存为作答序列，但累计不同题目数只计一道。

### 19.13 练习一直是那几道题，能换一批吗？

当前每个知识点使用最多 3 道的固定抽样题组，并在本次运行中缓存；没有换一批、随机刷题或完整题库分页入口。重启也不保证取得不同题目。

### 19.14 历史完成路径为什么也能点题号？

它提供重新进入相关练习的入口。再次提交会影响新的作答记录和后续诊断，但不会把历史完成路径变回未完成。题号能否打开还受当前题库及题组可用性影响。

### 19.15 百分比是我的正确率吗？

不是当前已做题目正确率。它是模型的预测参考值；“综合掌握度”也是当前保留的界面名称，不能视为正式掌握度测量。

### 19.16 为什么做对一道题后，预测值不一定明显上升？

模型结合最近作答序列计算结果，不是每答对一道就固定加分。网络或预测服务未成功更新时，还可能显示上一次的值。

### 19.17 没有网络可以做哪些事？

可以查看随应用提供的图谱和已经保存的部分记录；已缓存内容的可见性取决于当前运行状态。新题目加载、在线图片、判题、诊断和 AI 回复均依赖网络或服务，不提供完整离线学习流程。

### 19.18 我的用户名与助手叫我的方式为什么不同？

当前个人资料、首页通用称呼和助手摸底信息没有做统一个人账户联动。修改“我的”页面姓名不会自动替换这些地方。

### 19.19 为什么资料年级只有大学和研究生？

当前个人展示页保留这些既有选项。数学助手的摸底选择在独立区域提供小学三至五年级，二者不联动。

### 19.20 可以上传自己的头像吗？

当前只能选择六个内置文字头像，未实现相册和拍照上传。

### 19.21 在应用里哪里切换界面颜色？

没有单独开关。配色跟随鸿蒙系统的浅色／深色模式，在设备系统设置中切换，最新实际效果仍需真机验收。

### 19.22 为什么完成整条路径后首页没有任务了？

整条路径已归档到“路径 → 已完成”。当前任务区域随之清空，可到助手生成并接受下一条建议。

### 19.23 桌面卡片为什么显示另一门课程？

卡片展示最近使用课程的快照。打开应用切到想显示的课程，再等待卡片同步。当前没有单卡固定课程设置。

### 19.24 卡片上还留着旧任务，可以继续点吗？

应用会重新验证该任务是否仍属于当前路径且尚未完成。过期入口会转向当前路径或助手，不会直接按旧待办启动练习。

### 19.25 换手机后输入原来的姓名，可以恢复记录吗？

不能。姓名不是登录账号，当前没有相应的账号云同步和用户可操作的导入恢复功能。

### 19.26 我可以只撤销一次错误提交吗？

当前没有单条作答删除或撤销按钮。可以重新练习并形成新作答；任务完成标记和累计题数仍按各自规则计算。

### 19.27 程序的示例通过了，为什么正式判题仍失败？

页面示例只覆盖题目的一部分情况。正式判题还会运行该题配置的其他测试，需要程序同时满足所有输入范围、边界条件和输出格式。

### 19.28 应用能直接修改手机上的 Java 文件吗？

当前练习使用页面代码输入区，可编写或粘贴代码；没有从文件管理器导入工程、编辑本机 Java 项目或打开外部 IDE 的入口。

### 21.2 术语对照

| 术语 | 在知径中的含义 |

| 课程 | 小学数学或 Java 数据结构，各自保留学习状态 |
