# 从源码运行知径

当前仓库提供鸿蒙应用源码。使用支持 HarmonyOS 6.0.2（API 22）的 DevEco Studio，可打开工程并运行 App。

## 打开工程

1. 克隆仓库，或下载源码 ZIP 并完整解压。
2. 在 DevEco Studio 中打开包含 `build-profile.json5`、`AppScope/` 和 `entry/` 的仓库根目录。
3. 等待 IDE 完成项目同步，选择 `entry` 运行配置和匹配的鸿蒙运行设备。
4. 点击 Run，启动知径并选择课程。

DevEco 需具备匹配的 SDK。首次在自己的真机安装时，按 IDE 提示完成正常的自动签名；工程不包含他人的个人证书、私钥或设备授权文件。

## 使用现有云服务

App 默认连接现有云后端，运行应用无需修改后端地址。Java 判题、学习预测和 AI API 调用均在云端执行，手机或电脑无需另行安装 Python、Java 判题服务、容器或数据库，也无需填写 AI 密钥。

运行设备需要联网。云服务不可用时，在线判题和 AI 建议可能无法使用，部署一套本地环境并不是普通用户使用应用的必要步骤。

## 工程结构

| 目录 | 内容 |
| --- | --- |
| AppScope/、entry/、hvigor/ | 鸿蒙应用、页面资源和构建配置 |
| server/ | 后端源码、运行模型、题库及配图 |
| scripts/ | 状态回归、运行资产与发布检查工具 |
| design/brand/ | 应用图标的矢量源文件 |
| docs/ | 使用手册和运行说明 |
| third_party/ | 第三方许可文本 |

后端源码供项目维护使用，普通运行 App 不需要启动这些文件。运行资源随仓库提供，不依赖研究子仓库或原始学生数据。

## 检查与维护

构建后可运行 `scripts/test-*.cjs` 中的状态回归，按脚本要求传入本机 DevEco SDK 的 TypeScript 模块路径。

检查后端运行资源完整性：

```bash
python scripts/check-runtime.py
```

提交前检查私密配置及禁止上传的文件：

```bash
python scripts/check-publish.py
```

这些是维护工具，不是普通用户使用应用的前置步骤。完整功能操作见[使用手册](知径产品介绍与使用说明.md)。
