# 平板与 2in1 界面适配

现有 App 共用手机、平板和 2in1 界面及业务逻辑，使用 HarmonyOS 6.0.2（API 22）。

界面根据应用窗口的实际 vp 宽度变化：小于 600 vp 显示底部导航，600–1199 vp 显示紧凑侧边导航，1200 vp 起显示完整侧边导航。扣除导航后的内容宽度达到 840 vp 时，首页、助手、图谱详情、答题、学习路径和我的使用双栏。课程选择在宽窗口并排显示。

图谱支持鼠标滚轮缩放及放大、缩小、居中按钮，窗口缩放时保留视图中心和缩放比例。宽屏 Java 练习采用题干与代码分栏。聊天摸底选项支持换行和滚动，聊天及编辑区随窗口宽度调整。侧边导航支持 Alt+1 至 Alt+5，聊天发送支持 Ctrl+Alt+S。

助手及用户头像使用鸿蒙系统智能、人物符号。AI 正常回复末尾以红色显示“（本内容由ai生成）”；历史回复兼容此提示，固定欢迎语、错误提示和用户消息不标记。提示由界面显示，不进入发送给模型的聊天正文。

验证入口为 scripts/test-adaptive-layout.cjs 及原有学习状态、首页同步、Agent 建议、答题和卡片回归脚本。布局测试执行 ArkTS 编译产物的回调，并使用框架桩；不能替代真机渲染。需在真实设备检查横竖屏、分屏、连续缩放、软键盘和鼠标键盘操作。
