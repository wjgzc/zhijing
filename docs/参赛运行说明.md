# 知径参赛运行说明

## 运行方式

本作品是鸿蒙原生 App。**评委打开本仓库中的鸿蒙工程，构建并运行 App 后，直接使用现有云后端。**

```text
评委的手机／鸿蒙模拟器
        ↓
    知径 App
        ↓ 网络请求
现有云后端：题库、知识追踪、Java 判题、AI API
```

无需在评委电脑上安装 Python、Java 判题服务、Docker、数据库，也不需要填写任何 AI API 密钥。仓库内的 `server/` 是完整作品的后端源码与运行资产，供审阅和留档；不是参赛运行的前置部署步骤。

## DevEco 打开和运行

1. 克隆仓库，或下载源码 ZIP 并完整解压。
2. 在 DevEco Studio 中选择打开项目，打开包含 `build-profile.json5`、`AppScope/` 和 `entry/` 的仓库根目录。
3. 等待 IDE 完成正常项目同步。工程使用 HarmonyOS 6.0.2（API 22），评审用 DevEco 应具备匹配的 SDK。
4. 选择 `entry` 运行配置，选择支持对应 API 的鸿蒙运行设备。
5. 点击 Run，启动“知径”。
6. 选择“小学数学”或“Java 数据结构”，即可进行图谱浏览、在线练习、助手规划和路径管理。

无需修改代码中的后端地址。App 的现有地址继续指向作品云服务。

### 真机签名说明

源码工程已删除提交者本机的证书路径、签名密码与设备授权文件。DevEco 在评委自己的真机上首次安装时，可能要求按其设备与账号完成正常的自动签名流程。

这一步由鸿蒙设备安装机制决定，不是额外部署作品业务环境。不能把提交者的私钥和个人设备授权文件公开进仓库来绕过它。工程可在不含个人签名的状态下完成构建；本轮已实际验证构建成功。

如果参赛平台要求“完全不操作签名且直接在指定设备安装”，需要由该平台提供认可的设备或签名分发方式，不能保证一份个人调试签名适用于所有评审真机。

## 推荐体验顺序

1. 课程选择页：查看“知径”名称、图标和双课程入口。
2. 图谱页：点模块进入子级，双指缩放、单指移动，点知识点看详情。
3. 数学：进入有题目的知识点，完成选择题或填空题，查看判分与解析。
4. Java 数据结构：查看中文题意、英文原文和示例，提交完整 Java 程序；代码由云端隔离判题。
5. 助手页：完成基础、目标、时间选择，生成建议，点击知识点链接查看图谱。
6. 点击建议的“✓ 接受”，到路径页查看任务和题目进度。
7. 完成任务，查看路径归档；到“我的”查看学习看板。
8. 支持的真机上，可通过系统桌面添加“知径学习待办”服务卡片。

逐个按钮、保存方式和异常提示见 [完整产品介绍与使用说明](知径产品介绍与使用说明.md)。

## 联网与云服务

- 评审设备需要能访问作品当前云服务。
- 题目、数学判分、预测、Java 判题和 AI 回复通过云后端提供，AI 密钥只保留在云后端。
- 没有网络时，不能完整体验在线判题及 AI 规划。
- 比赛期间需要作品维护方保持现有云服务可用，而不是由评委重新部署。
- 云服务不可用时，App 的报错不代表需要评委安装一套本地 Java 或 AI 环境。
